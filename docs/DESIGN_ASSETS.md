# SANRO AI — Design Asset Prompt Library

Single source of truth for SANRO visual assets.

## Global visual direction
Premium modern Indian EdTech: intelligent, warm, optimistic, clean, academic, human and slightly futuristic. Use the provided Dribbble references for quality/composition/polish only; do not copy them.

Prefer:
- premium SaaS/EdTech composition
- controlled whitespace
- 24–32px rounded cards
- soft depth and subtle shadows
- Poppins headings + Inter body
- real students/teachers/parents
- academic intelligence/data motifs
- restrained gradients
- high-quality 2.5D/3D/editorial illustration

Avoid:
- generic AI robots
- glowing brains
- childish cartoon visuals
- generic stock-photo clichés
- excessive neon
- text baked into images
- logos/watermarks
- competitor/Dribbble copying

## Production rules
- Use exact pixel dimensions below.
- Keep aspect ratio; never stretch.
- Web: prefer WebP/AVIF; SVG for vector assets.
- PNG only when transparency is required.
- Provide mobile crops where composition needs it.
- Lazy-load below-the-fold media.
- Use next/image or equivalent responsive loading.
- Every informative image needs alt text.
- Decorative images use empty alt text.
- Do not put important readable text inside generated images.
- If using internet assets, record source/license in `docs/DESIGN_ASSETS.md`.

If an existing image is better than generation, search for legally usable assets. Prefer official/open-license/stock sources with clear licensing. Never scrape or copy copyrighted Dribbble/competitor artwork. Record the source/license.

# Performance

Audit every image for:
- intrinsic dimensions
- file size
- responsive variants
- lazy loading
- crop
- alt text
- caching/CDN

Do not add images merely to fill whitespace. Every visual must improve comprehension, trust or polish.
