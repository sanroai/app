# SANRO AI — Website

## 1. Purpose

Explain in seconds what SANRO is, why it matters, and how it works — and drive
demo/app requests. Rebuilt from zero as a premium EdTech site, not an
afterthought.

## 2. Pages

Home · Features · How SANRO Works · For Students · For Teachers · For Schools ·
For Parents · Pricing · About · Contact/Demo · FAQ · Privacy · Terms.

## 3. Homepage Narrative

Primary loop: **LEARN → ASSESS → DIAGNOSE → FIX → RETEST → IMPROVE**.

- Hero: precise positioning ("Traditional learning library + assessment-driven
  remediation"), NOT "AI-powered learning platform".
- Student visual, product UI visuals, teacher visual, assessment/diagnosis
  visual, app download section (only when real APK/store links exist — APK link
  is live at `/downloads/sanroai.apk`).
- CTAs: Start / Request Demo / Explore SANRO.

## 4. Design

Premium, modern, trustworthy, educational — not childish, not generic-SaaS.
Strong typography, generous spacing, high-quality imagery, product screenshots,
subtle motion, role-specific visuals, accessible contrast, responsive.
Violet brand (#7c3aed). Poppins headings, Inter body.

## 5. Contact Flow

Contact/demo form must post to a real route (rebuild removes the pre-rebuild
dead `/api/contact` gap).

## 6. SEO

Metadata per page, OpenGraph, sitemap + robots (robots disallow `/app/`,
`/login`, `/register`), `metadataBase: https://sanroai.com`.
